# Orbit

A modern and responsive finance dashboard built with React and Tailwind CSS that helps users track income, expenses, and spending insights through an elegant analytics-driven interface.

---

## Features

- Dashboard analytics
- Add / Edit / Delete transactions
- Advanced transaction filtering
- Dark mode support
- Interactive charts & insights
- LocalStorage persistence
- Mock API integration
- Responsive modern UI
- Empty state handling
- Smooth animations and transitions

---

## Preview

### Dashboard
- Balance overview
- Income vs Expense analytics
- Spending by category
- Recent transactions
- Insights panel

### Transactions
- Search transactions
- Filter by category/type/month

- Dynamic empty states

## Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/LaibaFirdouse/Orbit
```

### 2️⃣ Navigate to project

```bash
cd Orbit
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start development server

```bash
npm run dev
```
